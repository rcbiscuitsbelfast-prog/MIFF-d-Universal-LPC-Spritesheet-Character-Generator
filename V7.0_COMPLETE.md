## ?? KEY FUNCTIONS

### compositor.js

**`loadAllAnimationsForLayer(basePath, color, animations)`**
- Loads ALL 15 animations for one layer
- Returns object with animation images
- Fallback to walk if specific animation missing

**`createCompositeSpriteSheet(options)`**
- Creates 832x3456 canvas
- Loads all animations for all layers
- Composites them row by row
- Returns image + canvas

**`getAnimationRow(animationName, direction)`**
- Maps animation+direction to correct row in sheet
- Used by render() to find correct frame

### builder.js Changes

**`loadCharacter(gender, animation)`**
- Now calls createCompositeSpriteSheet()
- Builds complete master sheet
- Stores in state.compositeSpriteSheet

**`render()`**
- Simplified from 100+ lines to 10 lines
- Draws from composite sheet
- Uses getAnimationRow() for positioning
- Perfect alignment guaranteed

**`exportCharacter()`**
- Exports state.compositeCanvas
- Full 832x3456 sprite sheet
- NOT just one frame!

**`reloadAllCustomizationSprites()`**
- Rebuilds entire composite sheet
- Called when any customization changes
- Ensures all layers update together

**All `window.select*()` functions**:
- Now call reloadAllCustomizationSprites()
- Rebuilds composite on every change
- Ensures perfect synchronization
