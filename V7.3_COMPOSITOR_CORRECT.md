## ?? WHY THIS IS CORRECT

### Problem with Per-Frame Compositing:
```javascript
// OLD WAY (BROKEN):
render() {
  drawImage(bodySprite, ...);   // Walk animation
  drawImage(hairSprite, ...);   // Walk animation
}

// User changes to slash
// hairSprite is still from walk! ?
// Hair "sticks" at wrong position!
```

### Solution with Composite Sheet:
```javascript
// NEW WAY (CORRECT):
// When hair is selected, build composite:
compositeSpriteSheet = composite(
  body[walk],  body[slash],  body[thrust],  ...
  hair[walk],  hair[slash],  hair[thrust],  ...
)

// Render just reads from composite:
render() {
  drawImage(compositeSpriteSheet, row, col);
}

// Hair is ALWAYS correct! ?
```
