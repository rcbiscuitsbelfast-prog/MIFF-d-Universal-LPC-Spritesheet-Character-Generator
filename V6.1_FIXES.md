### New Functions
- `reloadAllCustomizationSprites()` - Reloads all clothing for current animation
- `loadBodyOptions()` - Shows body extras (wings, tail, fins)
- `loadHeadOptions()` - Shows head extras (horns, ears, etc.)
- `selectBodyExtra()`, `selectHeadExtra()`, `selectHeadExtraColor()` - Handlers

### Animation Sync
All sprite loading functions now use `state.currentAnimation`:
```javascript
async function loadHairSprite() {
  const anim = state.currentAnimation; // ? Uses current animation
  const animConfig = CONFIG.animations[anim];
  const animDir = animConfig.dir;
  const path = `/spritesheets/hair/${hair}/adult/${animDir}/${color}.png`;
  // Loads correct animation frame!
}
```
