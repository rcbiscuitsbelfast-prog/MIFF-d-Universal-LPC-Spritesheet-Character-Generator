### Changes

#### 1. Updated Server API (`/api/assets`)
Enhanced to handle nested directory structures:

```javascript
// Before: Only returned top-level directories
basePath = path.join(config.spritesheetsPath, category);

// After: Handles complex paths
if (category === 'hair' && subcategory) {
  basePath = path.join(basePath, subcategory, 'adult', animation);
}
if (category === 'torso' && subcategory) {
  basePath = path.join(basePath, 'clothes', subcategory, gender, animation);
}
if (category === 'legs' && subcategory) {
  basePath = path.join(basePath, subcategory, gender, animation);
}
```

**API Endpoints Now Support**:
- `/api/assets?category=hair` ? Lists all hair styles
- `/api/assets?category=hair&subcategory=long&animation=walk` ? Lists colors for long hair
- `/api/assets?category=torso&subcategory=shirt&gender=male&animation=walk` ? Lists shirt colors
- `/api/assets?category=legs&subcategory=pants2&gender=male&animation=walk` ? Lists pants colors

#### 2. Updated Client-Side Loading

**loadHairOptions()**:
- Fetches ALL 103 hair styles from `/api/assets?category=hair`
- Filters out files (only directories)
- Gets colors dynamically based on current animation
- Display names formatted (e.g., "bangs_long" ? "Bangs Long")

**loadTorsoOptions()**:
- Lists all actual clothing items
- Gets colors dynamically based on current animation + gender
- Supports: blouse, blouse_longsleeve, corset, longsleeve, robe, shirt, shortsleeve, sleeveless, tunic, vest

**loadLegsOptions()**:
- Fetches all leg item directories
- Gets colors dynamically based on current animation + gender
- All 13 leg types available

#### 3. Enhanced Color Support

Added 30+ color mappings to `getColorHex()`:
- Hair colors: ash, blonde, carrot, chestnut, dark_brown, ginger, gold, navy, ruby_red, etc.
- Clothing colors: bluegray, charcoal, forest, lavender, leather, maroon, teal, walnut, etc.

#### 4. Animation-Aware Loading

All options now load based on `state.currentAnimation`:
```javascript
const anim = state.currentAnimation;
const animConfig = CONFIG.animations[anim];
const animDir = animConfig.dir;

// Use current animation when fetching colors
fetch(`/api/assets?category=hair&subcategory=long&animation=${animDir}`);
```

This ensures colors/options match the current animation being displayed!

### Technical Details

**Asset Directory Structure**:
```
/spritesheets/
  hair/
    {style}/          ? 103 styles
      adult/
        {animation}/  ? walk, run, slash, etc.
          {color}.png
  
  torso/
    clothes/
      {item}/         ? 12+ items
        {gender}/     ? male, female, teen
          {animation}/
            {color}.png
  
  legs/
    {item}/           ? 13+ items
      {gender}/
        {animation}/
          {color}.png
```

**Async Loading Flow**:
1. User clicks "Customize"
2. `enterCustomizeMode()` ? `showCategory('body')`
3. `showCategory()` ? `await loadCategoryContent()`
4. `loadCategoryContent()` ? `await loadHairOptions()` / `loadTorsoOptions()` / etc.
5. Functions fetch from API, parse results, generate HTML
6. User sees ALL available options!
